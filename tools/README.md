# tools

Small standalone utilities that aren't skills, prompts, or agents — browser
extensions, userscripts, and other bits of tooling that make day-to-day work
less annoying.

Each tool lives in its own folder with a README covering what it does and how to
install it.

| Tool | What it does |
| --- | --- |
| [`github-sticky-nav/`](github-sticky-nav/) | Keeps GitHub's repo nav and PR tab strip reachable while you scroll. Ships as both a Chromium extension and a Tampermonkey userscript. |
